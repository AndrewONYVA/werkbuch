# Werkbuch

A Bauhaus-style planner for writing a novel, in the spirit of Scrivener.

- **Characters**: main characters, sub-characters and bit-parts. Main characters get a five-point arc (Starting point, Catalyst, Midpoint shift, Crisis, Transformation).
- **Five acts**: Exposition, Rising Action, Climax, Falling Action, Resolution, each with a corkboard of scenes.
- **Scenes**: location and world-building, what the main characters learn, cause and effect, plot progression, and a draft with word count.
- **Flash parts**: break each scene into beats with action, cause and effect, story progression and arc influence.
- **Export**: a Word manuscript (title page, one chapter per scene, Garamond, 6 × 9 in) or the whole plan as Markdown.

It is a single `index.html` with no build step. Your work is saved in your browser's local storage, so use **Back up (.json)** on the Overview to keep a copy you can restore on another device.
